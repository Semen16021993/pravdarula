# Публикация всего проекта

Отдельные frontend-only/backend-only команды не нужны. Согласованный процесс описан в [yandex-serverless.md](./yandex-serverless.md): одна команда запускает проверки и определяет необходимые обновления всего приложения.

```bash
cd ~/Desktop/pravdarula && ./deploy-yandex.sh
```

После закрепления API на стабильной версии, если менялся только интерфейс, универсальный скрипт после сравнения с последним успешным релизом не создаёт версию API и не обновляет Gateway. Общая бизнес-логика, импортируемая API, выбирает обе затронутые части. Первое применение без baseline считается полным релизом и требует отдельного подтверждения.

Это не команда для немедленного запуска: первая сверка production, принятие baseline и публикация требуют отдельного согласования. В ходе разработки скрипт не запускался.
При pending-релизе та же команда предлагает RECOVER. Перед первым запуском обязательны проверки из [инструкции](./yandex-serverless.md), отдельно согласованные отчёты совместимости и проверка Yandex CLI/YDB на Mac; локальные тесты не заменяют эти проверки.
